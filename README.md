# style-3.css

Feuille de style pour une plateforme de contribution audio/vidéo, ambiance éditoriale, palette indigo/ochre/argile.

- Variables couleurs dans :root (indigo, bone, ink, ochre, clay, thread)
- Polices : Newsreader pour les titres, IBM Plex Mono pour labels/boutons, Work Sans pour le texte courant
- nav : sticky, logo animé, recherche
- hero : fond sombre, waveform animée
- interfaces : maquettes de téléphone (accueil, enregistrement, détail)
- problem : liste en deux colonnes
- process : 4 étapes en grille
- example : carte avec lecteur et citation
- contribute : formulaire
- recorder / video-recorder : enregistreurs audio et vidéo
- entries-grid / categories : contributions déjà soumises
- footer : appel à l'action final
- Animations désactivées si prefers-reduced-motion
- Breakpoints : 560px, 720px, 760px, 800px, 900px
